Add Wire Copy to your browser

Three steps, about a minute. When you’re done, this page carries on by itself.

  1. 1

    Open Extensions in a new tab

    chrome://extensions

    Then press ⌘T ⌘V return

    Then press Ctrl+T Ctrl+V Enter

  2. 2

    Turn on Developer mode

    It’s the switch in the top-right corner of the Extensions page.

    Developer mode
  3. 3

    Load the Wire Copy folder

    Click Load unpacked (top-left), then choose this folder:

    Load unpacked Pack extension Update
    the WireCopy-Extension folder

    In the folder picker: ⌘⇧G→ ⌘V→ return→ Select

    In the folder picker: Ctrl+L→ Ctrl+V→ click Open

    In the folder picker: Ctrl+V in the folder box→ Enter→ Select Folder
