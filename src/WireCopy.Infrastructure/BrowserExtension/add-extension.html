Add Wire Copy to your browser

Three steps, about a minute. This page carries on by itself when you’re done.

  1. 1

    Copy the Wire Copy folder

    the WireCopy-Extension folder

    You’ll paste it in step 3 — no need to come back here.

  2. 2

    Open Extensions, turn on Developer mode

    ⌘T→ type chrome://extensions→ return

    Ctrl+T→ type chrome://extensions→ Enter

    Then flip the Developer mode switch in the top-right corner.

  3. 3

    Load Wire Copy

    Click Load unpackedLoad unpacked at the top-left, then paste the folder into the picker:

    ⌘⇧G→ ⌘V→ return→ Select

    Ctrl+L→ Ctrl+V→ Open

    Ctrl+V in the folder box→ Enter→ Select Folder
